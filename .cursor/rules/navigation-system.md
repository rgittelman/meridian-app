# Meridian — Navigation system

Persistent single-layer bottom navigation for short, interrupted phone sessions. Aligns with `information-architecture.md` (Focus, Plan, Life, Capture).

---

## Meridian Navigation System

Meridian uses a **persistent single-layer bottom navigation** architecture optimized for busy adults using phones in short, interrupted sessions.

Primary navigation contains exactly **4 tabs**:

1. **Focus**
2. **Plan**
3. **Life**
4. **Capture**

- **No** hamburger menus.
- **No** hidden navigation.
- **No** deep hierarchy complexity.

---

## Navigation philosophy

Navigation should feel **psychologically invisible**.

Users should never need to remember:

- where features live
- complicated paths
- layered organizational systems

Everything important should exist within **one tap**.

---

## Capture decision

**Capture is a PRIMARY tab**, not a floating action button.

**Reason:**  
Cognitive offloading is a core emotional behavior, not a secondary utility action.

Capture represents **relief from mental load**.

---

## Tab behaviors

### Focus

- Default launch destination
- AI-ranked priorities
- Immediate clarity surface
- “What matters now”

### Plan

- Preserves timeline / scroll context
- Calm future visibility
- Schedule awareness

### Life

- Slower emotional pacing
- Reflective experience
- Reduced urgency
- More breathing room visually

### Capture

- Opens instantly into input-ready state
- Keyboard immediately active
- Voice capture instantly accessible
- **Goal:** thought captured within **2 seconds**

---

## Modal strategy

**Prefer:**

- bottom sheets
- contextual overlays
- expandable cards

**Avoid:**

- unnecessary full-screen transitions
- deep navigation stacks
- route fragmentation

---

## Gesture principles

Gestures should **accelerate** interactions, never **hide** them.

**Global rules:**

- swipe down dismisses sheets
- predictable back behavior
- no hidden core interactions
- long press for secondary acceleration only

---

## Complexity rule

No core workflow should require:

- more than **2** navigation layers
- more than **1** stacked modal
- more than **one-handed** interaction

If it does, **simplify the workflow**.

---

## Platform variants

### iOS

Use:

- native bottom tab bar
- large titles
- translucent materials
- spring motion physics
- native swipe-back gestures

### Android

Use:

- Material 3 navigation bar
- edge-to-edge layouts
- Android-native back handling
- slightly denser spacing rhythm

## UX standard

The navigation system should feel:

- immediate
- calm
